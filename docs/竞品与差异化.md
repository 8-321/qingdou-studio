# 竞品拆解与差异化

## 1. 市面玩家分四层

| 层级 | 代表 | 强项 | 致命短板 |
|---|---|---|---|
| 提取工具 | 轻抖、各类"去水印/文案提取"小程序 | 链接覆盖广、免费、上手快 | 只给一整段文字；无结构；无留存；广告多 |
| 数据平台 | 蝉妈妈、飞瓜、灰豚 | 账号/商品数据全 | 贵（年费几千到几万）；不做逐句稿；不服务个人博主 |
| 转写工具 | 通义听悟、讯飞听见、录音转文字助手 | 长音频强、准确率高 | 不懂短视频；没有"爆款结构"；交互重 |
| 海外 | Notta、Otter、Eightify、Glasp、OpusClip | 体验好、全球化 | 中国平台不支持；按美元定价；不懂中文平台生态 |

**空档**：懂中国平台 + 懂短视频结构 + 价格亲民 + 有留存机制。这四件事目前没人同时做到。

## 2. 用户真实吐槽（决定产品优先级）

按出现频率排序（来自应用商店/小红书/贴吧的共性反馈）：

1. "提取出来一大坨，还得自己排版" → **清洗 + 分段 + 标点**
2. "不知道哪句是重点" → **结构卡**
3. "视频下架了/链接失效，我之前提取的也找不到了" → **云端素材库**
4. "一小时录音传到一半失败" → **分片续传**
5. "广告太多，看 5 条才给 1 次" → **额度透明 + 签到**
6. "会员买了发现长视频还是要另外付费" → **权益写清楚，不设隐藏门槛**
7. "抄了文案也不会拍" → **提词器 + 二创**

## 3. 五个差异化钉子（按投入产出排序）

### 钉子 1：逐句时间轴 + 点击回跳（成本最低，感知最强）
每条稿子按句切分，带 `start/end`。点句子 → 小窗播放器跳到那一秒；播放时当前句高亮跟读。
- 实现：ASR 自带时间戳，前端一个 `<video currentTime>` 即可。
- 价值：从"文字"变成"可对照的学习工具"。
- 竞品现状：几乎都没做。

### 钉子 2：爆款结构卡（核心记忆点）
把稿子拆成 5 段并给理由：

| 段 | 判定信号 | 输出 |
|---|---|---|
| 钩子 Hook | 前 3 秒 / 前 2 句；反问、反差、利益承诺、身份点名 | 原句 + 句式模板 + 强度分 |
| 痛点 Pain | 负向词、场景词、"你是不是…" | 原句 + 目标人群 |
| 证据 Proof | 数字、案例、对比、权威 | 原句 + 可信度评分 |
| 转折 Turn | "但是/其实/直到/我发现" | 原句 + 转折类型 |
| 行动 CTA | "评论区/主页/下单/关注" | 原句 + CTA 类型 |

再给一个 0-100 的"可复用性评分"（钩子强度 30 + 结构完整 25 + 信息密度 25 + CTA 清晰 20）。
- 实现：规则命中 + 小模型打分，**必须输出理由**，否则用户不信。
- 价值：这是"我们和轻抖"的分水岭。

### 钉子 3：对标账号日更监控（留存核武器）
输入主页链接 → 每天 8:00 抓新增作品 → 自动提取 → 推送"3 条新爆款，已拆解"。
- 免费 1 个账号，会员 10 个，团队 50 个。
- 成本可控：只对新作品跑，且字幕优先。
- 价值：把"想起来才用"变成"每天必看"。次留能从 20% 拉到 35%+。

### 钉子 4：提词器 + 一键二创（闭环）
结构卡 → 选行业/语气 → 出 3 版稿 → 全屏提词器（可调字号/速度/镜像）→ 直接开拍。
- 提词器是纯前端，成本几乎为 0，但用户感知极强。
- 二创走国产模型（混元/deepseek-flash），单次成本 <0.01 元。

### 钉子 5：字幕优先 + BGM 分离（成本与准确率双杀）
- 有字幕直接取，0 ASR 成本、100% 准确。
- 无字幕先做人声分离再转写，嘈杂视频准确率 +8-15pp。
- 结果：同样定价下毛利高 20-30pp，可以打价格战。

## 4. 不做什么（同样重要）

- ❌ 不做视频去水印、不提供原视频下载（合规红线，也是微信审核高危项）
- ❌ 不做通用"AI 写作"（打不过大厂）
- ❌ 不做账号数据大盘（打不过蝉妈妈）
- ❌ 首发不做小红书（投入产出比最差）
- ❌ 不做二级现金分销（微信规则）

## 5. 定价与心理

| SKU | 价格 | 锚点设计 |
|---|---|---|
| 免费 | 0 | 3 次/日，刚好够"尝到甜头但不够用" |
| 次数包 | 9.9 / 30 次 | 给"偶尔用"的人，避免被月费劝退 |
| 月卡 | 19.9 | 主推；对标一杯奶茶 |
| 季卡 | 49 | 标"省 9.7 元" |
| 年卡 | 128 | 标"每月 10.6 元"；转化率通常最高 |
| 团队 | 99/月/5 人 | 按"每人 19.8"表达 |

**关键**：会员权益只写 4 条，且全部可感知（无限次、长音频、结构卡、导出）。写 10 条等于没有权益。

## 6. 护城河（老实说）

单点功能没有护城河。真正的壁垒按强度排序：
1. **对标账号库 + 历史稿件库**（用户数据，越用越难走）
2. **解析稳定性**（长期运维积累，新玩家要踩 6 个月坑）
3. **结构标注的行业模板**（按赛道积累，如美妆/教育/本地生活）
4. **团队协作关系链**（B 端一旦嵌入工作流就很难换）

所以产品从第一天就要把"素材库"和"监控"当主功能，而不是附属功能。
