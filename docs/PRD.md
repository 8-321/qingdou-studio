# PRD · 文案提取工作台（小程序 + APP）

版本 v1.0 ｜ 2026-11-04 ｜ 目标：可提审、可变现、可维护

---

## 1. 背景与定位

市面上的"文案提取"工具（轻抖、去水印助手、各类提取小程序）本质都是：**粘贴链接 → 出一段文字 → 复制走**。
用户拿到文字后仍然要自己做三件事：判断哪句是钩子、重写成自己的、拍出来。

**我们的定位**：把"提取"往后延两步，做成 **逆向工程 + 再生产** 的工作台。

> 对外一句话：**别人的爆款，你的脚本。**
> 对内一句话：用"结构卡 + 逐句时间轴 + 对标监控"把一次性工具变成每天要打开的生产力工具。

## 2. 目标用户

**首个 MVP 只服务前两类**，其余用"上传提取"兜底。

## 3. 核心用户故事

1. 我在抖音刷到一条 80 万赞的口播，复制分享链接，粘进来，25 秒后拿到逐句稿，点任意一句能跳回原视频那一秒。
2. 我想知道它为什么爆，点"结构卡"，看到 0-3s 钩子是什么句式、痛点在第几句、CTA 怎么收。
3. 我把结构卡套到我的行业，一键生成 3 版口播稿，直接进提词器开拍。
4. 我关注了 5 个对标账号，每天早上收到"昨日新增 3 条，已提取"的推送。
5. 我有一段 1 小时 40 分的采访录音，从微信聊天文件选进来，6 分钟后拿到带说话人的稿子，导出 Word。
6. 我在视频号看到一条，链接粘不进来，按提示"保存视频→上传"，一样出稿。

## 5. 关键规则

### 5.1 额度

| 用户类型 | 次数 | 日上限 | 单条时长 | 保留原文 |
|---|---|---|---|---|
| 未登录 | 不能提交 | — | — | — |
| 免费 | 每个功能终身 2 次 | 50（`FREE_DAILY_QUOTA`） | 10 分钟 | 24 小时 |
| BYOK 会员 | 自己的 Key，不限功能次数 | 50 + 签到加成 | 180 分钟 | 文本永久 |
| 团队 | 同 BYOK，共享后台 | 50 + 签到加成 | 180 分钟 | 文本永久 |

- 扣费优先级：**BYOK → 免费次数 → 会员 → 付费额度**。
- 签到 / 看视频 / 邀请得到的是「链接提取次数」，不是现金。
- 任务失败或内容安全拦截，自动退回本次次数。
- 失败任务**不扣次数**（以任务终态为准）。
- 原视频/原音频 **24 小时自动删除**，只留文本与波形摘要。

### 5.2 任务状态机

```
created → queued → resolving → downloading → extracting_audio
        → transcribing → cleaning → structuring → done
                                              ↘ failed(可重试1次)
```
- 每个状态都有 `progress`(0-100) 与 `stage_text`，前端不猜。
- 超时：单任务 20 分钟未完成 → failed，自动退款次数。
- 失败码：`LINK_INVALID / PLATFORM_BLOCKED / NO_AUDIO / TOO_LONG / ASR_ERROR / COPYRIGHT_BLOCKED`，每个码对应一句人话提示 + 一个替代动作（如"改用上传"）。

### 5.3 链接识别

输入框接受任意文本，服务端执行：
1. 提取所有 `https?://` 与裸短链（`v.douyin.com/xxx`）。
2. 跟随 ≤3 次跳转，记录最终域名。
3. 命中平台表 → 进入对应 resolver；未命中 → 提示"暂不支持，可上传文件"。
4. 同一链接 24 小时内已解析 → 直接返回缓存结果（省成本，用户感知"秒出"）。

### 5.4 内容安全（必须做，否则提审不过）

- 文本过微信 `msgSecCheck`；音频过 `mediaCheckAsync`（或第三方审核）。
- 命中敏感内容：任务置 `blocked`，不展示内容，不退次数但给"申诉"入口。
- 不做"去水印"字样的任何宣传；不提供原视频下载。
- 结果页固定展示："仅供个人学习参考，请勿用于侵权用途"。

## 10. BYOK（用户自带密钥）与免费额度

### 10.1 规则

| 功能 ID | 用户看到的名字 | 免费次数 | 用完后 |
|---|---|---|---|
| `link_extract` | 链接提取 | 2 次（终身） | 订阅 或 平台额度 |
| `article_extract` | 公众号提取 | 2 次 | 订阅 |
| `audio_extract` | 录音提取 | 2 次 | BYOK ASR 或额度 |
| `video_extract` | 相册视频提取 | 2 次 | BYOK ASR 或额度 |
| `structure` | 结构卡 | 2 次 | BYOK LLM |
| `rewrite` | 二创 | 2 次 | BYOK LLM |

- 免费次数**终身**，不是每日；防薅靠 `openid + unionid + 手机号`。
- 签到每天额外 +1 次 `link_extract`，兼顾日活与成本。
- 同链接 24h 内重复提取不扣次数（缓存去重，待实现）。
- 第 3 次不直接报错，弹三选一：用自己的 Key / 买托管额度 / 签到。

### 10.2 密钥边界

| 类型 | 字段 | 可否用户自带 |
|---|---|---|
| LLM | `base_url + api_key + model`（OpenAI 兼容） | 可以 |
| ASR | OpenAI Whisper / 硅基流动 / 火山（AppID:Token:Cluster） | 可以 |
| 链接解析 | Cookie 池、签名、代理 | 不可以，平台维护 |
| 支付/短信 | 商户号、模板消息 | 不可以 |

### 10.3 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/features` | 每个功能的 used/free/left/plan/key |
| GET | `/api/keys` | 已配置密钥（仅掩码）与服务商预设 |
| POST | `/api/keys` | 保存密钥（先测试，失败不保存） |
| POST | `/api/keys/{id}/test` | 重新测试 |
| DELETE | `/api/keys/{id}` | 删除 |

额度不足返回 `402 TRIAL_ENDED`，附 `options: [byok, credits, signin]`。

### 10.4 安全要求（必须）

1. AES-256-GCM 信封加密；主密钥放环境变量/KMS，数据库只存密文。
2. 任何接口、日志、埋点都不得返回或记录明文，只返回 `****后四位`。
3. 保存前发一次最小请求测试（5-8 秒超时），失败不落库。
4. `base_url` 必须 HTTPS + 域名白名单 + 拒绝内网 IP（防 SSRF）。
5. 一键删除立即失效；换 Key 不影响历史稿件。
6. 配置页明确告知：音频/文本会发送给用户选择的服务商。

### 10.5 商业化对应

- BYOK 年卡 ¥128：AI 成本用户自付，平台收解析与工作台。
- 托管月卡 ¥39 / 300 次：平台出 Key，适合怕麻烦的商家。
- 企业私有化 ¥3-10 万/年：部署到客户服务器，全部自带 Key。

## 13. 导出与素材库（2026-11-05 新增）

### 13.1 设计原则

- **导出不扣次数**：次数在出稿时已扣，导出是取回自己的结果。
- **能打开才算导出成功**：Word / Excel 必须被 Office / WPS 正常打开，不能只验证「有字节」。
- **零依赖生成**：docx / xlsx 直接写 OOXML，不引入 python-docx / openpyxl，部署包更小。
- **素材库是工作台，不是回收站**：搜索、筛选、收藏、标签、批量导出，一条龙。

### 13.2 导出格式

| 格式 | 必含内容 |
|---|---|
| TXT | 全文 |
| Markdown | 标题、平台、时长、来源、全文、逐句表、结构卡、二创 |
| SRT | 标准毫秒时间轴，剪映可直接导入 |
| DOCX | 排版正文 + 逐句 + 结构卡 + 二创；批量导出时每条一页 |
| XLSX | 任务 / 序号 / 开始 / 结束 / 文案，带自动筛选 |
| JSON | segments / structure / rewrites 全量 |
| ZIP | 每条一个文件 + `_目录.txt` |

### 13.3 素材库

- 搜索：标题 + 正文，400ms 防抖。
- 筛选：平台、状态、收藏、标签。
- 标签：每条 ≤8 个，单个 ≤10 字；标签云按使用次数排序。
- 分页：20 条/页，返回 `total` / `has_more`。
- 批量：勾选后合并导出 Word / Excel，或打包 ZIP。

### 13.4 接口
