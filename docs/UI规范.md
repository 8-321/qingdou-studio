# UI 规范 · 极简工具风

## 1. 设计定位

去掉所有"纸感、宋体、暖棕、渐变光晕"。
关键词：**白、黑、一个蓝、细线、留白**。
参考气质：Linear 的克制 + Notion 的留白 + 剪映的专业度。
目标：用户第一眼看到的是"内容"，不是"装修"。

## 2. 色板

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#F1F2F4` | 页面外底色（原型展示用） |
| `--paper` | `#FFFFFF` | 应用底色 |
| `--paper2` | `#F6F7F8` | 次级底、输入框底 |
| `--ink` | `#0A0A0B` | 主文字、主按钮 |
| `--ink2` | `#5F6368` | 次级文字 |
| `--ink3` | `#9AA0A6` | 辅助/占位 |
| `--line` | `#ECECEE` | 分割线、卡片描边 |
| `--blue` | `#2563EB` | 唯一强调色：选中、进度、链接、主 CTA |
| `--blue-soft` | `#EEF3FF` | 强调底色 |
| `--green` | `#0B7A4B` | 成功、已配置 |
| `--green-soft` | `#E9F7F0` | 成功底色 |
| `--gray-soft` | `#F2F3F5` | 标签底 |

**规则**：一屏最多出现 1 处蓝色实心面积。蓝色只表示"当前/可点/进度"，不做装饰。

## 4. 栅格与圆角

- 屏宽 390，左右边距 20，内容宽 350。
- 卡片圆角 16；按钮 12；输入框 10；标签 999。
- 卡片阴影：`0 1px 2px rgba(10,10,11,.03)`，仅此一档。
- 间距基数 4：4/8/10/12/16/20/24。

## 6. 12 屏信息架构

```
首页 ──粘贴──▶ 解析中 ──▶ 结果页 ──▶ 结构卡 ──▶ 二创 ──▶ 提词器
  │                │
  ├─上传───────────┘
  ├─素材库
  ├─福利中心 ──▶ 会员
  ├─我的 ──▶ API 密钥（BYOK）
  └─邀请
```

| # | 页面 | 核心 |
|---|---|---|
| 01 | 首页 | 粘贴框 + 体验次数 + BYOK 入口 |
| 02 | 解析中 | 5 阶段进度 + 可后台 |
| 03 | 结果页 | 逐句时间轴 + 复制/导出 |
| 04 | 结构卡 | 5 段拆解 + 评分 + 理由 |
| 05 | 二创 | 3 版稿 + 语气滑杆 |
| 06 | 提词器 | 全屏滚动 + 字号/速度 |
| 07 | 上传 | 相册/录音/聊天文件 |
| 08 | 素材库 | 搜索/标签/批量导出 |
| 09 | 福利 | 签到/广告/积分 |
| 10 | 会员 | 套餐/支付/兑换码 |
| 11 | **API 密钥** | 免费额度、ASR/LLM 密钥、加密说明 |

## 7. API 密钥页（新增）

结构从上到下：
1. 蓝色说明卡：AI 成本你自付，平台只收解析与工作台。
2. 免费体验：4 行（链接/公众号/录音/视频），每行右侧 `1/2`。
3. 我的密钥：ASR、LLM、链接解析三张卡。
4. 主按钮：添加/更换密钥。
5. 安全说明：AES-256-GCM、只显示后四位、可删除、内容会发送给所选服务商。

密钥弹层：
- 顶部拖动条 + 关闭。
- ASR / LLM 两段切换。
- 服务商 chip（DeepSeek、混元、通义、硅基流动、自定义）。
- API Key 输入框（`type=password`，可切换明文）。
- Base URL（可选）。
- "测试并保存"主按钮，失败不保存。

## 8. 动效（沿用）

- 页面转场 280ms `cubic-bezier(.2,.8,.2,1)`。
- 进度环 400ms 线性；评分环 800ms。
- 标签出现 stagger 40-60ms。
- 只动画 `transform`/`opacity`。
- 遵循系统"减弱动态效果"。

## 9. 无障碍

- 正文对比度 ≥4.5:1；`--ink3` 只用于非关键信息。
- 支持系统字号 1.0/1.3/1.6；卡片高度自适应。
- 320px 下粘贴框降到 120，平台 chip 换行。
- 密钥输入支持粘贴、显示/隐藏、清空。
