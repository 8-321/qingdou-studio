# 合规与风险

> 这个品类最大的成本不是服务器，是**审核与投诉**。以下每一条都建议在开发前确认。

## 1. 小程序提审

### 类目
- 首选：`工具 → 效率`
- 备选：`工具 → 信息查询`
- **不要选**：视频、影视、直播、教育（会要求额外资质）

### 审核备注模板（直接抄）

> 本小程序是个人学习用途的文字整理工具。用户粘贴自己有权访问的公开内容链接，系统仅提取其中的语音并转写为文字，用于笔记与学习。
> 1）不提供视频/音频下载，不提供去水印，不破解任何技术保护措施；
> 2）原文件 24 小时内自动删除，仅保留文字；
> 3）已接入微信内容安全接口（msgSecCheck / mediaCheckAsync）；
> 4）所有结果页展示"仅供个人学习参考"；
> 5）提供侵权投诉入口，承诺 72 小时内处理。

### 审核高危词（界面、介绍、截图里都不要出现）
`去水印` `无水印` `破解` `下载视频` `搬运` `一键伪原创` `洗稿` `爬虫` `全网抓取`

### 常见驳回原因与处理
| 驳回理由 | 真实原因 | 处理 |
|---|---|---|
| 涉及未经授权的内容获取 | 文案里有"下载/去水印" | 全文替换为"文字整理/学习笔记" |
| 类目不符 | 选了视频类 | 改工具-效率 |
| 缺少隐私指引 | 未配置收集项 | 补隐私保护指引并弹窗 |
| 诱导分享 | 邀请文案写"转发得现金" | 改"邀请得次数"，去掉现金与强制分享 |
| 内容安全 | 未接安全接口 | 接入并保留调用日志 |

## 2. 版权与平台规则

| 风险 | 说明 | 我们的做法 |
|---|---|---|
| 复制他人文案 | 文案本身受著作权保护 | 定位"学习/研究/评论"；默认仅自己可见；不提供公开分享页 |
| 平台 ToS | 抖音/小红书/YouTube 均禁止未授权抓取 | 只处理用户主动提交的单条链接；不提供批量爬取接口给用户；不绕过 DRM |
| DMCA §1201（美国） | 规避技术保护措施可能违法 | 不破解加密流；不下载付费/会员内容；提供 abuse 通道 |
| 原视频传播 | 转存即侵权 | **只取音频、不存视频、24h 删除** |

**产品红线**：不做"批量下载某账号所有视频"，不做"原视频保存"，不做"去水印"。这三件事会把产品从"工具"变成"侵权工具"。

## 3. 支付合规

| 平台 | 规则 | 做法 |
|---|---|---|
| 微信小程序 iOS | 禁止虚拟支付 | iOS 隐藏购买按钮，只留兑换码/引导下载 APP |
| 微信小程序 安卓 | 可用微信支付 | 正常售卖 |
| APP iOS | 必须走 Apple IAP | 抽成 30%（小企业 15%） |
| APP 安卓 | 微信/支付宝 | 正常 |
| 自动续费 | 需显著告知、可随时取消 | 默认不做自动续费，降低投诉 |

**建议**：小程序只卖"次数包 + 兑换码"，会员主推 APP。这样既合规，又能把用户导到 APP（留存更高）。

## 4. 分销与邀请

微信规则明确禁止：
- 多级分销（二级及以上返佣）
- 以现金/实物为奖励的诱导分享
- 强制分享后才能使用

**合规做法**：
- 一级邀请，奖励为"次数/会员天数"，不是现金。
- 好友必须主动注册，不能"点击即绑定"。
- 不要求"分享到 3 个群"才能解锁。
- 邀请文案不出现"赚钱/返现/佣金"。

> 如果一定要做现金返佣，只能放在 APP 内，且不超过一级，并做税务代扣。

## 5. 隐私（个人信息保护法 + 小程序规范）

必须做到：
1. 首次进入弹隐私协议，**单独同意**后才能调用麦克风/相册/文件。
2. 隐私政策写明：收集什么、为什么、存多久、给谁、如何删除。
3. 提供"注销账号"与"删除数据"入口（不能只留客服邮箱）。
4. 音频属于个人信息（可能含他人声音），需说明"上传前请获得对方同意"。
5. 数据出境：如有海外节点，需单独告知并取得同意（或海外用户单独部署）。
6. 未成年人：不面向 14 岁以下；如无法判断，默认按成年人服务并在协议中声明。

## 6. 内容安全

- 文本：微信 `msgSecCheck`（同步）。
- 音频：`mediaCheckAsync`（异步，需回调）。
- 命中处理：任务置 `blocked`，不展示内容，提供申诉；同一用户连续命中 3 次，限制当日使用。
- 保留调用日志 ≥6 个月（监管要求）。

## 7. APP 上架

| 项 | 要求 |
|---|---|
| 软著 | 上架国内安卓商店必备，提前 30 天申请 |
| 隐私合规检测 | 工信部 164 号文；首次启动必须弹隐私弹窗，同意前不得收集 IMEI/位置 |
| 权限 | 最小化：只申请麦克风、相册/存储、网络；不要通讯录、位置 |
| 隐私政策 | 必须可在线访问（HTTPS），不能是本地文件 |
| 内容分级 | 工具类，无年龄限制；但需有举报入口 |
| iOS | 4.2 最低功能要求：不能只是网页套壳；IAP 必须完整 |

## 8. 风险预案

| 事件 | 影响 | 预案 |
|---|---|---|
| 某平台解析全面失效 | 该平台用户流失 | 熔断 + 引导上传 + 48h 内修复 + 公告 |
| 小程序被下架 | 收入归零 | APP/公众号/H5 三通道并行，私域沉淀 |
| 收到律师函 | 法务成本 | 立即下线相关内容、保留日志、委托律师回函、绝不硬刚 |
| ASR 供应商涨价/断供 | 成本上升 | 双供应商 + 本地 faster-whisper 兜底 |
| 数据泄露 | 致命 | 最小化存储、加密、24h 删除、定期渗透测试 |

## 9. 上线前法务清单

- [ ] 用户协议 + 隐私政策（在线可访问）
- [ ] 侵权投诉入口 + 72h 处理承诺
- [ ] 内容安全接口调用日志
- [ ] 数据删除与账号注销可用
- [ ] iOS 端无虚拟支付入口
- [ ] 邀请机制无多级返佣
- [ ] 所有页面无"去水印/下载视频"字样
- [ ] 软著/ICP/小程序认证齐全
