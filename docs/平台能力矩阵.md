# 平台能力矩阵（真实可行性，不是宣传口径）

> 结论先行：**能"粘链接就出稿"的平台只有 8 个左右；视频号必须上传；小红书是长期维护项。**

## 1. 链接直提

| 平台 | 链接形态 | 实现方式 | 首版目标成功率 | 维护频率 | 主要风险 |
|---|---|---|---|---|---|
| 微信公众号文章 | `mp.weixin.qq.com/s/...` | 直接抓 HTML，解析 `#js_content` | 98% | 低（半年） | 图片外链防盗链；需服务端 UA |
| B 站 | `b23.tv/xxx`、`BV号` | 公开 API + wbi 签名；优先取 CC 字幕，无字幕取 DASH 音频 | 98% | 低 | 大会员/付费课程不可取 |
| 抖音 | `v.douyin.com/xxx` | 短链 302 → 取 item_id → 调详情接口（需 a_bogus/X-Bogus） | 85% | **2-6 周** | 签名算法变更、设备指纹、风控 |
| 快手 | `v.kuaishou.com/xxx` | 短链 → 详情接口（需 sig） | 80% | **3-8 周** | 同上 |
| 小红书 | `xhslink.com/xxx` | 短链 → 笔记页（需 xsec_token + 登录 Cookie） | 70% | **2-4 周** | 链接 token 短期有效；风控最严 |
| 微博 | `weibo.com/tv/show/...` | 页面内嵌 JSON | 85% | 中 | 部分需登录 |
| 西瓜/头条 | `ixigua.com/...` | 页面 JSON / yt-dlp | 85% | 中 | 与抖音同源风控 |
| 好看/皮皮虾 | 短链 | 页面 JSON | 75% | 中 | 流量小，优先级低 |
| YouTube / TikTok / IG / X | 标准 URL | yt-dlp + 住宅代理 | 70-90% | 中 | **数据中心 IP 被封**；版权与 ToS |
| 微信视频号 | `channels.weixin.qq.com/...` | **无法直提** | 0% | — | 无公开可访问 URL，需登录态私有协议 |

> 视频号替代方案（必须做进产品）：保存视频 → 上传；或录屏 → 上传。小程序里用 `wx.chooseMedia`，聊天里转发的用 `wx.chooseMessageFile`。

## 2. 文件上传

| 来源 | 入口 | 格式 | 备注 |
|---|---|---|---|
| 相册视频 | `wx.chooseMedia` / APP 相册 | mp4/mov | 小程序端先压缩到 720p 再传，省 60% 带宽 |
| 手机录音 | 文件选择 / 分享到微信 | m4a/mp3/wav/aac | iOS 录音默认 m4a |
| 微信语音 | 聊天文件 | **silk** | 必须转码：`silk-v3-decoder` → wav；微信语音单条 ≤60s |
| 微信聊天视频 | `wx.chooseMessageFile` | mp4 | 单文件上限按微信规则，超限走 APP |
| 网盘/电脑 | APP 文件选择 / 网页上传 | 全格式 | 网页版建议第 2 期做，成本低、拉新好 |

## 3. 成本与策略

| 策略 | 成本 | 准确率 | 何时用 |
|---|---|---|---|
| **字幕优先** | ≈0 | 98-100% | 平台有 CC/自动字幕（B站、YouTube、部分抖音） |
| 云端 ASR | 0.5-2.5 元/小时 | 92-97% | 默认 |
| 本地 faster-whisper | 电费 | 88-95% | 高峰削峰、敏感内容、成本兜底 |
| BGM 分离后再 ASR | +0.1-0.3 元/小时 | +8-15pp | 音乐大声、嘈杂、影视剪辑类 |
| 静音裁剪 (VAD) | -30~50% 时长 | 不变 | 所有长音频默认开 |

**关键结论：先把"字幕优先"做到极致，ASR 成本能降 40-60%。** 这是同类产品普遍没做好的地方。

## 4. 解析层工程要求

1. **独立微服务**：`resolver` 单独部署，可单独重启/换 IP，不拖垮主站。
2. **Cookie/账号池**：抖音/小红书需要，按平台隔离，失败自动摘除。
3. **代理池**：国内平台用国内机房；海外平台用海外节点 + 住宅代理（$3-8/GB）。
4. **SSRF 防护**：只允许白名单域名；解析后的 IP 不得是内网/回环；禁止 `file://`、`gopher://`。
5. **缓存**：同链接 24h 结果缓存（Redis），命中直接返回，成本骤降。
6. **降级链**：官方接口 → yt-dlp → 无头浏览器 → 提示上传。每一级失败都要有日志。
7. **可观测**：按平台统计成功率/耗时，掉到阈值自动告警（这是"消耗品"的运维前提）。

## 5. 上线顺序建议

```
第 1 批（稳）：公众号、B站、本地上传（相册/录音/文件）
第 2 批（量）：抖音、快手
第 3 批（难）：小红书（先只做图文 OCR，视频后置）
第 4 批（海外）：YouTube/TikTok（独立海外节点，与国内业务隔离）
```

不要把小红书放首发——它会吃掉你 30% 的开发时间，却只贡献 10% 的使用量。
