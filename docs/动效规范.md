# 动效规范

目标：**让"等待"变成"正在被处理"的确定感**，而不是炫技。
原则：短、稳、有因果。所有动效必须解释"发生了什么"，否则删掉。

## 1. 基础参数

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.2,.8,.2,1)` | 进入、展开、页面切换（默认） |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 退出、收起 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 仅用于"完成/奖励"的正反馈 |
| `--dur-1` | 120ms | 按压、hover、颜色 |
| `--dur-2` | 200ms | 卡片展开、标签出现 |
| `--dur-3` | 280ms | 页面转场（默认） |
| `--dur-4` | 420ms | 结果揭晓、评分环 |
| `--dur-5` | 800ms | 提词器启动、庆祝 |

**禁止**：超过 600ms 的常态动效；弹跳用于负反馈；同一屏超过 3 处同时动画。

## 2. 逐屏动效

### P1 首页
- 粘贴成功：虚线框 1 次 `scale 1 → 1.01 → 1`（180ms），平台 chip 依次点亮（40ms stagger），底部按钮由灰变墨（200ms）。
- 额度用完：按钮不下沉，改为抖动 2 次（±3px，120ms），同时 Toast "签到可 +1 次"。

### P2 解析中
- 进度环：`stroke-dashoffset` 线性过渡 400ms，数字用等宽字体**逐位滚动**（不是整体跳变）。
- 阶段项：当前项圆点做 1.4s 呼吸；完成后打勾用 `scale .6 → 1.15 → 1`（spring，260ms）。
- 背景：一条 1px 扫描线 2.8s 匀速循环（对应原型 `.poster .scan`）。
- 阶段切换时，文案 120ms 淡出 → 换字 → 120ms 淡入（不做位移，避免跳动）。
- 完成：环变墨绿，整体 `scale 1 → 1.02 → 1`，420ms 后跳结果页。

### P3 结果页
- 进入：海报 0.96 → 1（280ms），逐句稿整体上移 8px 淡入（延迟 80ms）。
- 点句子：该行背景 180ms 变朱砂底；左侧时间戳变朱红；播放器时间同步。**不做**整页滚动，只保证该行可见（`scroll-into-view`）。
- 跟读高亮：当前句左侧 3px 竖条，随音频推进平滑移动（transform，不用 height）。
- 复制：按钮 `scale .96`，Toast 从底部 12px 上浮 + 淡入，1.6s 后自动消失。

### P4 结构卡
- 评分环：0 → 目标值，800ms `ease-out`，数字同步滚动。
- 五段卡片：进入视口时依次淡入上移 12px，stagger 60ms（仅首次，滚动回看不再触发）。
- 标签色条：从 0 高度展开到满高（200ms），暗示"这是一段结构"。

### P5 二创
- 生成中：三张卡先显示骨架屏（灰块 shimmer 1.2s），再逐张替换（每张间隔 200ms）。
- 采用：卡片边框变墨绿 + 右上角打勾 spring 出现；其余卡片降到 60% 透明度。
- 滑杆：数值变化不做动画（即时），仅轨道填充色 120ms。

### P6 提词器
- 启动：进入全屏 280ms 淡入；文字从下方 20px 上移到 0。
- 滚动：`requestAnimationFrame` 匀速，默认 0.45px/帧（≈27px/s），可 0.5x-2x。
- 暂停：文字 120ms 内减速停止（模拟惯性），不要急停。
- 镜像/字号切换：120ms cross-fade，不做翻转动画（会晕）。

### P7 上传
- 选择文件后：卡片高度 0 → auto（200ms），进度条从 0 到实际值（线性）。
- 分片成功：进度条尾部一个 80ms 的高光扫过。
- 断点续传：显示"已恢复，从 42.4MB 继续"，不做弹窗。

### P8 素材库
- 列表进入：前 6 条 stagger 30ms；超过 6 条不延迟（避免长列表等待）。
- 多选：卡片 `scale .98` + 左上角勾选圈 spring；底部操作条从下方滑入 220ms。

### P9 福利
- 签到：按钮文字切换 + 日历当天格子 `scale 1 → 1.12 → 1`（spring），同时 6 个金色小点从格子向上飘散（600ms，仅一次）。
- 积分数字：滚动递增（400ms），不直接跳变。
- 广告回来：+1 次提示从顶部下落（200ms），2s 后自动收起。

### P10 会员
- 套餐切换：选中卡边框 160ms 变墨绿，价格数字 120ms 淡入切换。
- 支付成功：全屏 1 次极简庆祝（墨绿圆环扩散 + 文案），800ms 后回会员页，**不做彩带/金币**（与品牌不符）。

## 3. 性能红线

- 所有动画只用 `transform` 与 `opacity`，禁止动画 `width/height/top/left`。
- 小程序端：单页同时运行的动画 ≤ 3；长列表用 `recycle-view` 或分页。
- 低端机（Android 千元机）目标 50fps 以上；掉帧时自动降级为淡入淡出。
- 遵循系统"减弱动态效果"：关闭位移、缩放、视差，仅保留透明度与进度。
- 首屏动画必须在 `onReady` 后 100ms 内开始，不与数据请求抢主线程。

## 4. 触觉与声音

- 触觉：仅 3 处使用轻震 —— 签到成功、复制成功、支付成功。其余不用。
- 声音：默认全关。提词器可选出"节拍音"，默认关。
- 不做"叮咚"式提示音，办公场景容易社死。

## 5. 交付给开发的格式

每个动效在标注里写清 4 件事：
```
元素：结果页-句子行
触发：点击
属性：background-color / transform
时长：180ms
曲线：cubic-bezier(.2,.8,.2,1)
```
原型 `03-UI/prototype/index.html` 里的 transition 值即为基准，可直接抄。
