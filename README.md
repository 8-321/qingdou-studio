## 先读这 3 条，能省你 2 个月

| # | 事实 | 影响 |
|---|---|---|
| 1 | **微信视频号无法用链接解析**。视频号没有对外可访问的分享 URL，必须登录态 + 私有协议。全行业（含轻抖）都是"录屏/保存后上传" | 产品文案不能写"视频号链接秒提"，否则上线即差评。改成"视频号：上传视频/录屏提取" |

## 90 天路线（结论版）

| 阶段 | 时间 | 做什么 | 验收标准 |
|---|---|---|---|
| P0 验证 | 第 1 周 | 拿 60 条真实链接（每平台 10 条）跑通率测试 | 抖音≥8/10、B站≥10/10、公众号≥10/10；小红书<6/10 就先砍掉 |
| P1 MVP | 第 2-3 周 | 小程序 7 页 + 后端：公众号/B站/上传 + 字幕优先 | 单条 3 分钟视频 ≤25 秒出稿 |
| P2 主平台 | 第 4-5 周 | 抖音/快手/小红书 + 大文件分片 + 会员/签到 | 1 小时录音 ≤6 分钟；支付闭环 |
| P3 差异化 | 第 6-8 周 | 时间轴逐句、结构卡、提词器、二创 | 结构卡人工可用率 ≥70% |
| P4 提审上线 | 第 9-10 周 | 类目/隐私/内容安全/压测 | 审核一次过；P95 < 3s（接口） |
| P5 增长 | 第 11-13 周 | 邀请、监控对标账号、素材库 | 次留 ≥35%，付费率 ≥2% |

**先做哪一步**：P0 的 60 条链接测试。这一步花 1 天，能决定后面 3 个月做不做小红书。

## BYOK 商业模式（结论）

- 用户能自带的是"AI 的油费"（LLM / ASR Key），带不走的是"车和牌照"（链接解析、账号池、代理）。
- 主推 BYOK 年卡 ¥128：AI 成本用户自付，平台只收解析与工作台，毛利 85%。
- 托管月卡 ¥39 / 300 次：平台出 Key，毛利 50%，服务怕麻烦的商家。
- 企业私有化 ¥3-10 万/年：部署到客户服务器，全部自带 Key。
- 每个功能终身免费 2 次；第 3 次弹"用自己的 Key / 买额度 / 签到"，不直接报错。
- 密钥 AES-256-GCM 加密、只显示后四位、保存前测试、可随时删除。
- 已实现：订单/额度入账/幂等回调/兑换码/会员到期；未配商户号时自动降级兑换码。
- 已实现：火山 ASR 提交+轮询（本地假服务商联调通过）；火山、OpenAI Whisper、硅基流动可选。
- 已实现：链接回归工具，支持 60 条批量跑、按平台统计成功率。
- 已实现：管理后台 `/admin`（网页 + 手机端），可配置每个功能免费次数、激励视频上限、给用户补次数/额度/开会员、发兑换码、查审计日志。
- 已实现：每日签到（+1，连续 7 天再 +5）、邀请（双方各 +3，好友首次付费 +7 天会员）、激励视频（看完 +1，每日 5 次）。
- 已实现：微信内容安全（文本 msgSecCheck + 音频 mediaCheckAsync + 回调），拦截不扣次数、失败自动退回。
- 已实现：一键二创 3 版（无 Key 模板版 / BYOK 出成稿）+ 全屏提词器（自动滚动、调速、字号）。
- 已实现：小程序内直接录音（mp3，≤10 分钟）+ 相册视频 / 微信文件上传；免费单条 10 分钟，会员 / 自带 ASR Key 放宽到 180 分钟。
- 已实现：多格式导出（TXT / Markdown / SRT / Word / Excel / JSON / ZIP），Word 与 Excel 零依赖生成，Office 实测可打开。
- 已实现：素材库搜索（标题 + 正文）、平台筛选、收藏、标签云、分页、批量合并导出。
- 已实现：导出面板（格式说明）、可读文件名、单句复制；素材库长按改名/标签/删除、全选批量、按最长排序、下拉刷新。

## 变现结构（国内）

- 免费：每个功能终身 2 次（不是每天），单条 ≤3 分钟
- 签到：+1 次/日，连续 7 天 +5
- 激励视频：看完 1 条 +1 次，每日 5 次（eCPM 30-80 元，单次广告收入 0.03-0.08 元 > 单次成本 0.01-0.03 元，正毛利）
- 会员：月 19.9 / 季 49 / 年 128；次数包 9.9/30 次；团队版 99/月/5 人
- 邀请：双方各 +3 次；好友首次付费邀请人 +7 天会员。**只返次数和会员天数**（现金二级分销在微信生态违规）

## 美国市场（结论）

**不建议做通用 C 端"链接转文字"**——Notta / Otter / Eightify / Glasp 已经把价格打到 $0，且 YouTube 明确禁止下载，头部产品常年被发律师函。
**可行的是 3 条**：跨境卖家版（中英双语 + 卖点提取）、B 端 UGC 广告素材监控（$99-499/月）、白标 API。详见 `02-研究\美国市场可行性.md`。
